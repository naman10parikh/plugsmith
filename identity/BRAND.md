# BRAND — Plugsmith

## Name rationale

**Plugsmith** — a smith who forges plugs. A plug is the part that lets one thing connect to another in a
single motion; a plugin is how a repository's skills, agents, hooks and MCP servers connect to someone else's
coding agent in one install. The name pairs with its siblings: `hooksmith` forges hooks, `skillsmith` forges
skills, plugsmith forges the plugin that carries them all.

## Symbolic connection to the workflow

The workflow is **packaging**. A repository grows a harness piece by piece; plugsmith is the last step that
turns those pieces into something a stranger can install. Each build is a forge run: scan, shape the two files
Claude Code reads, then test the result against Claude Code's own validator.

## Tagline

**"Any repo, one plugin, one install line."**

## One-liner

Turn any repository into a Claude Code plugin and marketplace.
